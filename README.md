# Checklist-G

Site de checklists pour suivre ta progression dans tes jeux vidéo.

## Fonctionnalités

- Ajouter des jeux (Terraria, Skyrim, Valheim, etc.)
- Ajouter des étapes / tâches par jeu
- Cocher les étapes terminées
- Voir le pourcentage de progression
- Données sauvegardées automatiquement dans le navigateur

## Lancer le site

Ouvre `index.html` dans ton navigateur (double-clic sur le fichier).

Ou avec un petit serveur local :

```bash
npx serve .
```

Puis ouvre l'adresse affichée (souvent http://localhost:3000).

## Structure

- `index.html` — page principale
- `css/style.css` — styles (à améliorer plus tard)
- `js/storage.js` — sauvegarde des données
- `js/app.js` — logique de l'application
